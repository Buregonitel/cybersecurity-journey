# cybersecurity-journey
Общий репизиторий с прогрессом по месяцам (план обучения)

# Итоговый план обучения кибербезопасности с нуля за 6 месяцев

# Месяц 1: Основы IT,Linux и Network

Linux Deep Dive: Linux Journey + Bash scripting basics.
Networking Fundamentals: Cisco NetAcad — Networking Basics + Introduction to Networks.
Python Intro: Automate the Boring Stuff with Python — главы 1–12.
Практика: OverTheWire Bandit.
Цель: Комфорт в терминале, понимание сетей.

# Месяц 2: Введение в Cybersecurity + Hands-on

Основной курс: Google Cybersecurity Professional Certificate (Coursera, audit бесплатно) — Module 1–4.
TryHackMe: Pre Security path + Intro to Cyber Security.
Дополнительно: Cisco Introduction to Cybersecurity (бесплатно на NetAcad).
Практика: TryHackMe rooms (OWASP Top 10 basics, Nmap).
Проект: Настрой домашний lab (Pi-hole или simple firewall на Linux Mint).

# Месяц 3–4: Core Security Concepts + Подготовка к Security+

Security+ Prep: Professor Messer SY0-701 full playlist (YouTube, бесплатно — https://www.professormesser.com/security-plus/sy0-701/sy0-701-video/).
TryHackMe: Cyber Security 101 + SOC Level 1 paths.
Web Security: PortSwigger Web Security Academy — все labs.
Дополнительно: ISC2 Certified in Cybersecurity (CC) — бесплатный курс.
Практика: Daily rooms на TryHackMe/HackTheBox Academy (free tier).
Проекты: Vulnerability scanning (OpenVAS), packet analysis (Wireshark), simple Python security scripts.
Цель к концу месяца 4: Сдать mock-экзамены Security+.

# Месяц 5: Сертификация + Специализация

Полная подготовка Security+: Jason Dion или Messer practice tests (Udemy, часто на скидке ~10–15$). Сдай экзамен к концу месяца (если готов).
Offensive/Defensive: TryHackMe — Jr Penetration Tester path или Blue Team fundamentals.
Cloud Basics: Microsoft Learn Security paths (бесплатно) или AWS free tier security labs.
Практика: CTF на HackTheBox / PicoCTF.

# Месяц 6: Портфолио, Продвинутые темы + Подготовка к поступлению

Портфолио: 5–7 проектов на GitHub (CTF write-ups, home lab guide, web vuln reports).
Дополнительно: Burp Suite Academy (free) + Malware basics (на TryHackMe).
Сертификаты: Завершить Google Cert + ISC2 CC.
Для вуза: IELTS prep (если нужно) + черновик SOP.
Проекты: Собственный vulnerable lab + documentation; участие в 1–2 онлайн CTF.

Рекомендуемые платформы (все с free tier):

TryHackMe — основной hands-on.
Coursera (audit) + Cisco NetAcad.
YouTube: Professor Messer, NetworkChuck, John Hammond.
PortSwigger, OverTheWire, HackTheBox Academy.

Ожидаемый результат за 6 месяцев:

Security+ (или готовность к сдаче).
Google/ISC2 сертификаты.
GitHub-портфолио (10+ репозиториев).
